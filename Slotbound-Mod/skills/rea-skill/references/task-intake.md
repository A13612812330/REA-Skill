# 口语调用与信息补全

本文件统一维护 Komo-Skill、中文模糊路由和直接调用 REA 的逆向需求接收流程。自动选择 Skill 只表示进入准备阶段，不表示用户已授权执行目标分析。

## 识别

“我需要反编译”“帮我逆向 XXX”“分析这个安装包”“看看这个游戏的脚本和数值”等软件发行物研究，进入本流程。APK/IPA/EXE 只是目标线索，不能据此猜真实文件位置或引擎。

只问概念、数学逆向思维或已有完整源码的普通阅读，不要求用户填逆向表。用户当前在修改 Skill 规则，也不把其举例路径当成要分析的新应用。

## 准备阶段

从当前对话预填已知项，一次列出剩余信息，用大白话给出下面的补全单。未知填“待补充”；用户不必复制整段，直接回复缺失项即可。不索要敏感数据或要求其预先判断引擎。

```text
我会用 rea-skill 帮你研究这个应用，先确认以下内容：

应用/平台：<已知名称；Android、iOS、Windows等，不清楚可留空>
文件：<安装包或程序绝对路径，待补充>
目标：<想看代码、图片、数值，或研究哪个功能，待补充>
输出目录：<用户指定位置；未指定则提出独立目录建议，不创建>
授权范围：<请确认有权研究；已有明确说明则不再重复询问>

默认方式：先离线分析，不运行应用、不连接设备、不访问服务端、
不改原文件；缺少工具先说明，不自动安装。

拟执行流程：
1. 只读识别文件类型、版本、结构并记录校验值。
2. 检查本次需要的现有工具；缺项时说明可做与受阻部分。
3. 按实际格式提取可分析内容，恢复可读代码，整理相关资源和数值。
4. 追踪你指定的功能，保留对应文件、方法或引用证据。
5. 做获准范围内的结构/语法等检查，交付文件路径、结果和未验证项。

请补充缺失信息；确认以上范围后回复“按此方案开始”。
```

只有“研究应用”而没有具体目标时可给可选说明：查看可恢复代码结构、整理资源/数值、追踪一个指定功能。不替用户默认选择无限范围的“全部逆向”。

输出建议按目标选择独立 `games/<名称>-analysis` 或 `tools/<名称>-analysis` 目录；不用 `<名称>` 真创建目录，不拿本 Skill 所在目录或旧 Slotbound 项目接收新应用产物。

## 确认与执行

- **待补充**：缺路径/具体应用或研究目标，展示补全单后等待。可有未知平台，确认后识别，不要求用户懂技术栈。
- **待确认**：字段已齐但用户只补充信息，没有确认执行，简短复述本目标和离线范围，问一个合并确认问题，然后等待。
- **可执行**：必要信息齐全且明确确认本目标/方案，才进入 `SKILL.md` 的调查流程。补充字段时同时说“按此开始”可以合并完成，不再机械要求额外一轮。
- **续作**：已批准目标、问题和范围不变时，直接继续；换应用/版本或扩大范围时重新核对相应变更，不重复已知字段。

准备阶段只读 Skill 和既有上下文，不读目标内容或计算目标哈希，不创建目录，不调用解析器/反编译器，不执行安装/联网下载/设备操作。把确认边界理解成“还没写文件所以可以先偷偷分析”属于错误。

确认离线分析后，工具安装、目标执行、模块求值、注入、设备连接、重打包和远程发布仍是独立范围；逐项说明并按用户当前授权处理，不能从“开始离线分析”自动推导。

## 示例

用户：“我需要反编译。” -> 展示空缺模板和流程，等待，不搜索文件。

用户：“逆向这个游戏，看看伤害怎么算，包在某路径。” -> 预填路径和伤害计算目标，给离线范围和方案，等待确认；不转入 H5 游戏开发。

用户只回复一个 APK 路径 -> 补上路径，目标仍缺则补问；不能因为路径存在就启动 JADX。

用户：“目标是技能数值，按上面的离线方案开始。”且路径已知 -> 进入已批准的静态分析；缺工具说明，不自动安装。
